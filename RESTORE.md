# Magic Cosmetics UK site: app overlay

Only the files written for this site on top of the Higgsfield `scroll-scrub` website scaffold.
The `app/` files in this branch are byte-identical to the deployed Higgsfield build `ba20e8f` (checked 2026-11-11), except the three font files (see Fonts).
First pushed 2026-11-08, updated 2026-11-11 with the speed, share cover, Shop now and footer changes.

Copy the `app/` folder of this branch over a fresh scaffold checkout (same relative paths), then:

1. Patch `app/src/server.ts` so both `applySecurityHeaders(...)` calls receive `request` as a second argument.
2. Add the media that is produced separately under `app/public/assets/`: `world/scene-01..04` (`.mp4`, `-poster.webp`, `-mobile.mp4`, `-mobile-poster.webp`), `plates/powder-smoke.webp`, `lifestyle/barber-counter.webp`, `og/magic-og.jpg`.
3. `bun install && bun run build`.

## Shop now switch (read before launch)

`CHECKOUT_LIVE` in `app/src/site/data.ts` is `false`. While it is false, Shop now, Add to bag and the collection buttons go to the current store at magiccosmetics.co.uk (its real product and collection handles are mapped in `CURRENT_STORE_PRODUCTS` and `CURRENT_STORE_COLLECTIONS`) and the footer newsletter form is hidden.

Set it to `true` once the new store at shop.magiccosmetics.co.uk is live, and BEFORE magiccosmetics.co.uk is served by this site. Otherwise every buy button points back at this site.

## Share cover

`app/src/app-meta.json` points `og_image_url` and `marketplace_cover_url` at images on the Higgsfield CDN, and `app/src/site/seo.ts` uses `og_image_url` as the default share image. Those two image files are not in this repo.

## Fonts

`app/public/fonts` holds the unmodified fontsource latin files: Outfit variable (`@fontsource-variable/outfit` 5.3.0) and IBM Plex Mono 400 and 500, all under the SIL Open Font License 1.1.
The deployed build serves trimmed copies of the same three files (about 28 KB for Outfit and 7.7 KB for each Plex Mono, instead of 32 KB and about 15 KB each), so it is slightly lighter. The typefaces are the same.

## Not included on purpose

`node_modules`, `dist`, `packages/` (vendored scaffold), `src/routeTree.gen.ts` (generated by `tsr generate`), and the film, plate, barber and OG images.
